# Repository Instructions

## Environment Files

Do not access, open, read, search, inspect, or print the contents of `.env.dev`, `.env.local`, `.env.stage`, `.env.test`, or `.env.prod` for any reason. The only environment file that may be accessed is `.env.example`.

When configuration details are needed, use `.env.example` only. Do not use commands or tools that could expose the contents of the restricted files.

## Project Context

This project describes a Simple Bank fund-transfer feature. Follow the requirements in `docs/requirement-fund-transfer.md` and the project summary in `README.md` when making related changes.
